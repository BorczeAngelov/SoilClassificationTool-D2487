# Soil Classification Tool (USCS / ASTM D2487)

A web tool for classifying soils under the Unified Soil Classification System (USCS), ASTM D2487. Developed by Borcze Angelov for [Geohydroconsulting](https://ghk.com.mk/geohydroconsulting.html).

**Live tool:** https://borczeangelov.github.io/SoilClassificationTool-D2487/tool

This repository hosts the public deployment only (compiled build). The source code is private.
